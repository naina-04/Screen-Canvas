# Complete Keyboard Shortcuts Reference

| Shortcut | Description |
|---|---|
| `PageDown` | Next presentation slide |
| `PageUp` | Previous presentation slide |
| `Esc` / `V` | Desktop pass-through mode |
| `Ctrl+Shift+D` | Toggle Drawing Mode |
| `P` | Pen tool |
| `H` | Highlighter |
| `M` | Marker |
| `E` | Eraser |
| `N` | Numbered step badge |
| `F` | Spotlight focus |
| `K` | Laser pointer |
| `B` | Canvas backdrops |
| `Ctrl+Z` / `Ctrl+Y` | Undo / Redo |
| `Ctrl+S` | Save session snapshot |
